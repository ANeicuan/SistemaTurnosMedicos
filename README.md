## Introducción
En este proyecto se busca la digitalización y optimización a partir de un sistema de turnos manual. Se busca la eficiencia en una aplicación de sistema de turnos digital simple, que pueda crear, modificar y cancelar turnos según necesite el cliente, además de una automatización de notificaciones hacia el paciente a través de Whatsapp e Email. Busca resolver conflictos o errores humanos como por ejemplo: Sobreturnos o turnos extra.
